# Implementation of Dynamic Fire Injection Height in GFDL's Atmospheric Model (AM4.0): Impacts on Aerosol Profiles and Radiation

This study develops a more mechanistic dynamic fire injection height scheme in GFDL's Atmospheric Model version 4.0 and evaluates how it changes aerosol vertical structure and radiative impacts in global simulations.

![preview](https://i.imgur.com/0JJHsa2.png)

The work compares modeled injection heights against observations and examines how shifting from fixed plume heights to a dynamic representation changes aerosol profiles and the Earth's radiation budget.
